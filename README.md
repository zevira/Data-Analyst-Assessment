## Setup Instruction


1. SQL Assessment

A. Objective: Generate insights and visualizations related to inventory turnover, staff performance, customer purchase patterns, and sales.
B. Steps:
- Open the SQL Assessment notebook via https://colab.research.google.com/drive/1sODKnGK6cFNDBNuljQ4PJEHCBf4qWtNa?usp=sharing.
- Follow the sections in the notebook:
    a. Data Generation: Simulate data for multiple tables such as inventory, sales, staff.
    b. Data Join: Perform SQL joins between the tables to extract relationships and insights.
    c. Insights Generated:
        - Inventory Turnover Metrics per Branch: Calculate and display metrics to assess branch-level inventory efficiency.
        - Staff Performance and Sales: Analyze staff contributions toward sales targets.
        - Customer Purchase Patterns: Uncover trends in customer buying behavior.
    d. Dashboard Creation: Export summarized data and create visual dashboards for sales and product insights.


2. ETL Requirements

A. Objective: Implement data validation, cleaning, transformation, and error handling.
B. Steps:
- Open the ETL Requirements notebook via https://colab.research.google.com/drive/1k319gsmh4i8kDRUElHwsNjmtATADHGjf?usp=sharing.
- Follow the steps in the notebook:
    a. Data Validation: Check for missing or incorrect data entries in the dataset.
    b. Data Cleaning: Handle null values, duplicates, and incorrect formats.
    c. Data Transformation: Normalize data, create calculated columns, and ensure consistency.
    d. Error Handling: Include try-except blocks for robustness during the ETL process.
- Export the cleaned and transformed dataset for further analysis.


3. Data Visualization Assessment

A. Objective: Build a Tableau dashboard to present insights about cooperatives across Indonesia.
B. Steps:
- Open Tableau Desktop and load the prepared dataset.
- Follow these visualization steps:
    a. Distribution of Cooperative Types: Use a bar chart or pie chart to show cooperative types across different sectors/groups.
    b. Location of Cooperatives: Create a map visualization to display the geographic distribution of cooperatives across Indonesia.
    c. Male vs Female Members Comparison: Use a bar chart or side-by-side bar chart to compare the total number of male and female members in cooperatives.
    d. Top 5 Provinces: Create a ranking visualization (bar chart) to highlight the provinces with the highest number of cooperatives.
- Customize the dashboard layout to make insights easily interpretable and export the final dashboard.
